## ✦ Design Philosophy

The goal of this portfolio was to move beyond the traditional layout of:

> Hero → About → Skills → Projects → Contact

Instead, the website treats the portfolio as an **interactive digital space**.

3D objects, motion, depth, transitions, and interaction are used to guide visitors through the experience while keeping the interface clean and professional.

The visual direction focuses on:

**Minimalism × 3D × Motion × Technology**

---

## ✦ Performance

The portfolio is designed with performance in mind while maintaining an immersive visual experience.

Key considerations include:

- Optimized 3D rendering
- Responsive layouts
- Efficient animations
- Lazy loading where appropriate
- Reduced visual complexity on smaller screens
- Optimized assets
